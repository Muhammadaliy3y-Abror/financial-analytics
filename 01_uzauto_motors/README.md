# Financial Analytics — UzAuto Motors (2022–2025)

Automated financial performance analysis and visual dashboards for **UzAuto Motors JSC**, built with Python.

## 📌 Overview
This project analyzes UzAuto Motors' financial performance from FY 2022 to FY 2025, turning raw financial statements into actionable insights and publication-grade visual dashboards. It forms the foundation of an ongoing series evaluating corporate performance, operating efficiency, and capital structure across major global and regional companies.

## 🎯 Goals
- Automate financial statement analysis (revenue trends, margin compression, capital expansion).
- Build reusable Python scripts and chart visualization pipelines applicable to other brands.
- Practice quantitative financial modeling and corporate finance analytical skills.

## 🛠️ Tools & Technologies
- **Language:** Python 3.10+
- **Data Manipulation:** `pandas`, `numpy`
- **Data Visualization:** `matplotlib`
- **Data Ingestion:** `openpyxl` (Microsoft Excel file processing)

## 📊 What It Does
- Loads historical raw corporate statements (`uzauto_financials_2022_2025.xlsx`).
- Calculates key profitability ratios and structural metrics: Gross Margin %, Operating Margin %, Net Profit Margin %, and Return on Equity (ROE).
- Automates high-resolution (300 DPI) chart generation covering revenue vs. net income, margin trends, and capital structure expansion.
