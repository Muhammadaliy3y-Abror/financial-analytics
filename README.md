A data-driven financial modeling and ratio analysis portfolio evaluating corporate performance, operating efficiency, and capital structure dynamics across global and regional market leaders.

## 📊 Methodology Overview
Each brand analysis follows a structured four-phase pipeline:
1. **Data Ingestion:** Extracting raw corporate financial statements into Excel.
2. **Ratio Automation:** Scripting custom Python logic to calculate liquidity, profitability, and leverage metrics.
3. **Data Visualization:** Rendering high-resolution, publication-ready financial dashboards.
4. **Strategic Reporting:** Synthesizing quantitative insights into executive-level risk reports.
